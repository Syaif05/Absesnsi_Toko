# Revisi login dan perubahan PIN opsional — 10 November 2026

Permintaan pengguna dibatasi pada dua hal: mengganti total tampilan login agar sederhana pada HP mengikuti referensi baru, dan memindahkan perubahan PIN/password menjadi pilihan setelah login. Instruksi ini menggantikan ketentuan wajib ganti PIN awal pada PRD §2/§4 untuk PIN awal maupun hasil reset. Tidak merombak halaman bisnis lain.

Observasi referensi: latar putih keabu-abuan, judul terpusat, label singkat, input pill putih, ikon mata dalam field, tombol utama hitam dan panel konfirmasi putih dengan ikon berhasil. Pada HP form satu kolom, tanpa bingkai mockup perangkat, dengan ruang sentuh minimal 44 px dan font input 16 px. Login Google/Apple/registrasi tidak menjadi bagian kebutuhan aplikasi.

Komponen: LoginPanel menangani pemilihan Karyawan/Owner, ID, credential, loading dan pencegahan submit ganda. CredentialField menyediakan label, keyboard PIN dan tombol lihat/sembunyikan yang dapat dipakai keyboard/screen reader. LoginFeedback memakai dialog native dengan animasi slide/check untuk sukses dan shake untuk gagal, fokus modal dan dukungan reduced motion. AccountPanel menyediakan tautan halaman utama dan disclosure tertutup “Ganti PIN/password — Opsional”. Style baru hanya pada login/field terkait, bukan redesign dashboard.

Sukses baru ditampilkan setelah API login mengembalikan keberhasilan server. Tombol Lanjutkan menuju `/owner/dashboard` untuk owner atau `/attendance` untuk karyawan. Error jaringan/timeout/server ditampilkan dalam panel gagal dengan aksi Coba lagi. Di halaman tujuan, menu Akun membuka `/account`; ganti credential tidak menjadi interstitial atau prasyarat navigasi.

Backend: identity/login mengembalikan `pinChangeSuggested` sebagai informasi, menggantikan `mustChangePin`. Legacy kolom `employee_credentials.must_change_pin` tetap dipakai sebagai penanda PIN awal/reset dan menjadi false setelah perubahan sukarela; tidak membatasi akses. Tidak ada perubahan schema, migrasi cloud, penggantian password/PIN lama atau reset data. Initial PIN dan reset PIN mempunyai akses normal sesuai role/ownership; hak owner tetap tidak diberikan kepada employee. Semua redirect/guard PIN_CHANGE_REQUIRED dihapus. Status akun, hash Argon2id, rate limit, CSRF, cookie aman, revocation dan batas bisnis tetap berlaku. Ganti PIN/password sukarela tetap memvalidasi credential lama dan mencabut sesi setelah berhasil.

Verifikasi: 136 tes backend pada 11 file lulus. Tes mencakup initial PIN untuk context/absensi/koreksi milik sendiri, PIN hasil reset yang langsung dapat dipakai, role owner yang tetap ditolak, detail employee lain yang tetap ditolak, nonaktif/revocation dan perubahan credential sukarela. Build, TypeScript, lint dan scanner artefak browser dijalankan. Pengujian UI DOM/browser/screenshot/viewport/perangkat dan animasi runtime **tidak dijalankan** atas instruksi pengguna; responsivitas dan animasi belum dinyatakan lulus visual.

Review setelah deployment: buka `/login`, pilih akun, masukkan credential yang sudah diberikan, gunakan ikon mata bila perlu, lalu pilih Lanjutkan setelah sukses. Untuk perubahan credential, buka Akun → Ganti PIN/password. Aplikasi tidak meminta credential baru saat login pertama. Pilot/go-live tetap mengikuti checklist Fase 10.
